# Simosnap IRC Bot - GitHub Actions

## Come usarlo GRATIS con GitHub Actions

### 1. Crea un nuovo repository su GitHub
- Nome es: `simosnap-bot`
- Carica questi file

### 2. Vai su tab “Actions” nel repo GitHub
- Attiva le GitHub Actions se richiesto

### 3. Avvia il bot manualmente
- Vai su: `Actions > Run IRC Bot on Push`
- Clicca “Run workflow” in alto a destra

### Avvisi
- Il bot si fermerà dopo 6 ore (limite GitHub)
- Puoi rilanciarlo ogni volta manualmente
- Funziona perfettamente con Simosnap IRC
